# Farmer (бот-фармер): правила

- Бот должен делать ровно то, что описал пользователь, самым простым способом. Никаких добавленных ограничений, фильтров, чёрных списков, порогов, режимов (вроде GRIND), «защит» и эвристик, которых пользователь не просил. Лишнее в истории уже не раз приходилось удалять (см. `git log -10 -- farmer`).
- Перед правкой: `git log -5 -- farmer` и читать только нужную функцию в `farmer/src/farmer/Bot.hx` (grep по имени, не весь файл). Не откатывать решения, принятые в недавних коммитах.
- Баг: сначала причина по логу/коду (1-2 строки), потом одна минимальная правка. Если пользователь повторяет жалобу, прошлая правка не сработала: найти почему, не повторять её.
- Не знаешь, как работает функция игры: grep по `hlboot.dat` или справочным репозиториям, а не гадать. Если без лога из игры не определить причину, один раз попросить конкретный лог.
- Ответ: 3-5 строк, что исправлено и почему.
